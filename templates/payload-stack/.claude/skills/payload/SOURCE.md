# Source

This skill is Payload's own, copied unchanged from the `3.x` branch of
[payloadcms/payload](https://github.com/payloadcms/payload/tree/3.x/tools/claude-plugin/skills/payload)
(commit `88f06226f0`, 2026-09-03). It is the same skill `create-payload-app` installs for Payload 3
projects, so it describes the APIs this project's `payload` version has.

It covers Payload in general. The `stack-*` skills next to it cover how this project uses Payload:
read those first when the task touches tenancy, the dashboard, emails, scheduled actions or tests.

To refresh it, copy `tools/claude-plugin/skills/payload/` from the `3.x` branch over this folder
and keep this file.
