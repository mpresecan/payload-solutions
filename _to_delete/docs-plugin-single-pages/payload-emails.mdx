Automated emails (verification, password reset, invitations, receipts) are usually hard-coded templates that need a developer and a deploy to change a sentence. Payload Emails turns each email into a document in the Payload admin.

## Planned behaviour

- An `emails` collection with one document per email type, editable subject and body (rich text with variables such as `{{user.name}}`, `{{url}}`, `{{organization.name}}`).
- A registry API for other code (including Payload Stack and Better Auth callbacks) to request an email by key with variables; the plugin renders and sends through Payload's email adapter.
- Preview with sample data and a test-send button in the admin.
- Versions and drafts, so copy changes can be reviewed before they go live.
- Fallback to the code template when a document does not exist, so installing the plugin is safe.

## Status

Planned. Payload Stack's email pipeline (`src/emails`) is designed to be swapped for this plugin without touching call sites.
