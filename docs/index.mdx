## Contributing

Everything lives in one monorepo, MIT licensed: [github.com/mpresecan/payload-solutions](https://github.com/mpresecan/payload-solutions). Issues and pull requests are welcome. [Contributing](/docs/contributing) covers setup, tests, commit conventions and how pull requests are reviewed.

## Using these docs with an AI agent

The generated [LLM documentation index](/llms.txt) lists the published documentation pages and their descriptions. Give it to your coding agent as a starting point, then open the specific pages relevant to the task. The index is generated from the same source as this site, so it follows documentation changes automatically.

For work on Payload Stack projects, start with [Agentic development](/docs/payload-stack/agents) and the scaffolded project's `AGENTS.md`; that file contains project-specific commands and rules.
