title: Payload Action Scheduler
description: A WooCommerce-style action scheduler on top of Payload job queues. Planned.
---

Inspired by WooCommerce's Action Scheduler: schedule named actions with arguments, run them once or on a recurrence, group them, and inspect everything from the admin.

## Planned behaviour

- `scheduleAction(hook, args, at)` and `scheduleRecurringAction(hook, args, interval)` helpers built on Payload's job queue.
- An admin view listing pending, running, complete and failed actions with search, filters, retry and cancel.
- Claims and concurrency limits per group.
- Works with any runner: server cron, Vercel cron, or [Payload Clock](/docs/payload-clock).

## Status

Planned.
