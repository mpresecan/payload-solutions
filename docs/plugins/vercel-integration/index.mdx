---
title: Vercel Integration
description: Trigger Vercel deploy hooks from the admin and see deployment status. Planned.
---

Static or ISR sites need a rebuild when content changes. Vercel offers deploy hooks; editors should not need to know that.

## Planned behaviour

- A Deploy button in the Payload admin that calls a configured Vercel deploy hook.
- Optional automatic triggers on publish for chosen collections, debounced.
- Deployment status (building, ready, error) from the Vercel API, shown in the admin.
- Multiple environments (production, preview) with separate hooks.

## Status

Planned.
